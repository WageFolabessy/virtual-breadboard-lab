## 🎯 Apa itu Virtual Breadboard Lab? / What is VBL?

**Virtual Breadboard Lab (VBL)** adalah aplikasi web interaktif yang memungkinkan Anda merancang dan menguji rangkaian elektronika secara **gratis** dan **aman** langsung di browser. Tidak perlu membeli komponen fisik, tidak ada risiko merusak perangkat, dan tidak ada biaya langganan.

**Virtual Breadboard Lab (VBL)** is an interactive web application that allows you to design and test electronic circuits for **free** and **safely** directly in your browser. No need to buy physical components, no risk of damaging equipment, and no subscription fees.

### 🌟 Kenapa Menggunakan VBL? / Why Use VBL?

- 🎓 **Educational** - Ideal for students and electronics hobbyists

- 🔒 **Safe** - No risk of electric shock or damaging components
- 🌐 **Aksesibel** - Bisa diakses dari mana saja, kapan saja
- 🌐 **Accessible** - Can be accessed from anywhere, anytime

## 🚀 Cara Menggunakan VBL / How to Use VBL

### Langkah 1: Pilih Komponen / Step 1: Select Components

Klik komponen dari **Component Library** di sebelah kanan layar. Komponen tersedia dalam kategori:

- Power (Baterai)
- Output (LED, Buzzer)
- Control (Switch, Button)
- Logic Gates
- ICs (555 Timer)
- Semiconductors (Transistor, Diode)

Click components from the **Component Library** on the right side of the screen.

### Langkah 2: Letakkan di Breadboard / Step 2: Place on Breadboard

Drag & drop komponen ke breadboard virtual. Breadboard memiliki:

- **Power Rails** (garis horizontal merah/biru di atas dan bawah)
- **Terminal Strips** (garis vertikal di tengah)
- **Center Trench** (pemisah tengah)

Drag & drop components onto the virtual breadboard.

### Langkah 3: Hubungkan dengan Kabel / Step 3: Connect with Wires

Klik pada **node** (titik koneksi) pertama, lalu klik node kedua untuk membuat kabel.

Pilih warna kabel dari toolbar untuk organisasi yang lebih baik:

- 🔴 Merah - Untuk jalur positif (+)
- ⚫ Hitam - Untuk jalur ground (-)
- 🟢 Hijau, 🔵 Biru, 🟡 Kuning, 🟠 Orange - Untuk sinyal lainnya

Click on the first **node** (connection point), then click the second node to create a wire.

### Langkah 4: Test Rangkaian / Step 4: Test Circuit

VBL akan otomatis mengevaluasi rangkaian Anda secara real-time:

- LED akan menyala jika ada arus yang mengalir dengan polaritas benar
- Buzzer akan berbunyi jika aktif
- Sistem akan mendeteksi **short circuit** (hubung singkat) dan memberi peringatan

VBL will automatically evaluate your circuit in real-time.

### Langkah 5: Edit dan Eksperimen / Step 5: Edit and Experiment

- **Klik kanan** pada komponen untuk mengedit properti (nilai resistor, frekuensi timer)
- **Klik switch** untuk mengubah status ON/OFF
- **Hapus komponen/kabel** dengan tombol Delete
- **Undo/Redo** dengan Ctrl+Z / Ctrl+Y
- **Zoom** dengan scroll mouse atau tombol di pojok kiri bawah

## 📚 Tutorial & Contoh Rangkaian / Tutorials & Example Circuits

### 🔰 Pemula / Beginner

#### 1. Rangkaian LED Dasar / Basic LED Circuit

```
Baterai 9V (+) → Resistor 220Ω → LED Merah → Ground (-)
```

**Apa yang dipelajari / What you'll learn:**

- Cara menghubungkan komponen
- Fungsi resistor pembatas arus
- Polaritas LED (anode/cathode)

#### 2. LED dengan Switch / LED with Switch

```
Baterai 9V (+) → Switch → Resistor 220Ω → LED → Ground (-)
```

**Apa yang dipelajari / What you'll learn:**

- Kontrol aliran arus dengan saklar
- Rangkaian terbuka vs tertutup

#### 3. LED Paralel / Parallel LEDs

```
Baterai 9V (+) ┬─ Resistor 220Ω → LED 1 ┬─ Ground (-)
               └─ Resistor 220Ω → LED 2 ┘
```

**Apa yang dipelajari / What you'll learn:**

- Rangkaian paralel
- Pembagian arus
- Kebutuhan resistor untuk setiap LED

### 🔶 Menengah / Intermediate

#### 4. Transistor Switch / Transistor as Switch

```
Baterai 9V (+) → LED → Collector (NPN)
                       Emitter → Ground
Base ← Resistor 1kΩ ← Switch → Baterai (+)
```

**Apa yang dipelajari / What you'll learn:**

- Transistor sebagai electronic switch
- Perbedaan NPN dan PNP
- Amplifikasi arus

#### 5. Gerbang AND Sederhana / Simple AND Gate

```
Input A ─┐
         AND → Output → LED
Input B ─┘
```

**Apa yang dipelajari / What you'll learn:**

- Logika digital dasar
- Truth table
- Kombinasi gerbang logika

#### 6. 555 Timer LED Blink / 555 Timer LED Flasher

```
555 Timer IC (astable mode) → LED + Resistor → Ground
```

**Apa yang dipelajari / What you'll learn:**

- Cara kerja IC 555
- Astable mode untuk oscillator
- Mengatur frekuensi dengan resistor dan kapasitor

### 🔴 Lanjutan / Advanced

#### 7. Buzzer dengan 555 Timer / 555 Timer Buzzer

```
555 Timer → Buzzer → Ground
(dengan potentiometer untuk mengatur nada)
```

**Apa yang dipelajari / What you'll learn:**

- Audio tone generation
- Variable frequency oscillator
- PWM basics

#### 8. Half Adder Digital / Digital Half Adder

```
Input A ─┬─ XOR ─→ Sum Output
         │
Input B ─┼─ AND ─→ Carry Output
         └─ (inputs ke XOR)
```

**Apa yang dipelajari / What you'll learn:**

- Aritmatika digital
- Kombinasi multiple logic gates
- Binary addition

## ❓ FAQ / Frequently Asked Questions

### 🇮🇩 Bahasa Indonesia

**Q: Apakah VBL benar-benar gratis?**  
A: Ya, 100% gratis. Tidak ada biaya tersembunyi, tidak ada iklan, tidak ada limit penggunaan.

**Q: Apakah saya perlu menginstal software?**

- Apakah rangkaian tertutup (ada jalur dari + ke -)?

- Apakah polaritas LED benar (anode ke +, cathode ke -)?

### 🇬🇧 English

**Q: Is VBL really free?**  
A: Yes, 100% free. No hidden costs, no ads, no usage limits.

**Q: Do I need to install software?**  
A: No. VBL runs directly in your browser. Just open the website and start.

**Q: Will my circuits be saved?**  
A: Yes, VBL saves your circuits in the browser (local storage). Circuits will persist when you return.

**Q: What components are available?**  
A: VBL provides batteries, LEDs, resistors, switches, buzzers, transistors, diodes, logic gates, and 555 Timer ICs.

**Q: Can I use it on mobile?**  
A: VBL is optimized for desktop/laptop. Mobile support is experimental. For best experience, use a laptop or PC.

**Q: How do I delete a component?**  
A: Click the component you want to delete, then press Delete or click the delete button in the info panel.

**Q: Why isn't my LED lighting up?**  
A: Check:

- Is the circuit closed (is there a path from + to -)?
- Is there a current-limiting resistor?
- Is the LED polarity correct (anode to +, cathode to -)?
- Is there no short circuit?

## 🚨 Peringatan & Batasan / Warnings & Limitations

### ⚠️ Ini Adalah Simulator Logika / This is a Logic Simulator

VBL adalah simulator **logika**, bukan simulator **fisika**:

- ✅ Menunjukkan apakah rangkaian akan berfungsi secara logis
- ❌ Tidak mensimulasikan panas, voltage drop, atau noise
- ❌ Tidak menghitung arus dan tegangan dengan presisi engineering

VBL is a **logic** simulator, not a **physics** simulator.

### 💡 Gunakan untuk Pembelajaran / Use for Learning

VBL sangat baik untuk:

- ✅ Belajar konsep dasar elektronika
- ✅ Memahami cara kerja komponen
- ✅ Prototyping ide rangkaian
- ✅ Debugging logika rangkaian

Untuk design rangkaian profesional, gunakan tools seperti LTSpice, Proteus, atau Multisim.

For professional circuit design, use tools like LTSpice, Proteus, or Multisim.
